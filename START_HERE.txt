COMPOUND DAYS v36 — ONE PHONE EACH, ONE SHARED HOUSEHOLD
Build: v36-70429384

PLAY ONLINE
https://compound-days-waterside.superokie123.chatgpt.site

Give your partner viewer access to the private Site. Each person signs in with
their own ChatGPT account, on their own phone. One starts a household; the other
joins with its code. Each person chooses their own character and confirms ready.

Your shared home saves on the server. Opening this ZIP alone does not connect
two phones, and this export does not contain your live household database.

PLAY THE DOWNLOADED CLIENT LOCALLY
1. Extract the entire ZIP.
2. Open a terminal in the Compound_Days_v36 folder.
3. Run: python -m http.server 8000 --directory public/play
   Use python3 instead of python if needed.
4. Open http://localhost:8000 and choose "Play on this device".

This static command supports companion/local play only. Do not double-click
index.html: file:// can prevent asset loading.

SERVER DEVELOPMENT
Use Node.js >=22.13 and the pnpm version specified in package.json.
Install dependencies with: pnpm install --frozen-lockfile
Build with: pnpm build
Apply the supplied migration to a fresh local D1 database:
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_tense_hobgoblin.sql
Then run: pnpm dev
Use the local URL printed by the development server. A portable local preview
can simulate one development identity; real two-account play uses the hosted
Site's authentication and D1 database. Do not fake identity headers in production.

The .openai/hosting.json file retains this existing Site's project identity.
It is not a credential. Preserve it when updating this Site; use the normal
Sites creation workflow when deploying a separate copy as a different Site.
Dependencies, Git history, credentials and live database contents are excluded.
