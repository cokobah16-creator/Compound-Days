PLAY THIS COPY ON A COMPUTER
1. Extract the entire ZIP.
2. Open a terminal inside the extracted Compound_Days_v34 folder.
3. With Python 3 installed, run:
   python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
   On Windows, use:
   py -m http.server 8000 --bind 127.0.0.1 --directory dist
4. Open http://localhost:8000 in a WebGL-capable browser.
5. Press Ctrl+C in the terminal when finished.

Do not launch dist/index.html by double-clicking: file:// can block assets.
The game itself needs no package installation or build command.
The ZIP is a browser-game source package, not an iOS or Android installer.
On a phone, use the hosted link.

CONTROLS
Player 1: WASD to walk, E to act.
Player 2: arrow keys to walk, Enter to act.
Touch devices: on-screen sticks and action buttons.
Choose a companion for solo play, or two people on the same screen.
Open Tasks for the new Today / Almanac / Garden / Finds / People / Home journal.

SAVE AND VERIFICATION NOTES
Saves belong to the browser and origin. The hosted save does not automatically
transfer to localhost, another browser or another device. No personal saves
are included. Cross-device network co-op is not provided by this static copy.

The v34 tests and earlier regressions passed. WebGL visual review and real-phone
performance remain unverified; the preview browser could not create a WebGL
context. Images under check/review* are older offline reference renders, not
v34 gameplay screenshots. See README.md for the full limitations.
